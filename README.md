# 铁板定刻｜V4.2.1

这是 `20260720` 独立部署目录中的当前消费者版本。V4.2.1 复刻“起例—考刻—定分—启命书”的可感知流程，内部以全域条件事件图谱、确定性候选码本、贝叶斯更新、信息增益选条和封存模拟完成工程实现。用户可见“今解”只保留自然判断，精确计数口径与时间阈值仅用于内部推理和审核。

## 核心因果链

```text
完整出生资料
  → 回答前预生成 120 份候选命籍
  → 从固定命籍映射中取考刻条文
  → 应 / 不应 / 未明只更新候选后验
  → 达标则锁定一个刻分，否则明确待复
  → 只由锁定 Profile 与 BirthSeed 编纂前尘、后程
```

问答不会凭空创建人生事实；命书编译器以锁定候选为主体，并使用已确认的上下文过滤人物不存在或前置条件不成立的条目。相同 BirthSeed、内容版本、回答序列和锁定候选会得到相同命籍；更换出生日期、时辰、性别或出生地会改变候选码本。

## 产品流程

1. 输入出生年月日、约略时辰、出生地与命主信息；
2. 在该时辰覆盖的 120 个分钟候选中起局；
3. 每轮呈现一条带固定卷号、条号、定数的旧事条文；
4. 用户只回答“应 / 不应 / 未明”，通常在 12—24 轮内定刻；
5. 达不到预设置信门槛时显示“待复”，不强行定刻；
6. 定刻后揭示具体时分和命籍编号；
7. 命书从锁定命籍另取 6—10 个前尘节点，并从当前年龄逐年编至寿限；近年一年一条，中程两年一条，远程三年一条。

页面不显示问卷题数或百分比进度。用户看到的是铁算盘数序、十二卷卷次、条文编号，以及“初起 / 复算 / 刻渐明 / 旁证 / 刻成”的仪式状态。

## V4 数据与算法

- 546 个原子事实，覆盖家门、学路、事业、财务、关系、身心、人事、转折八域；
- 546 条单命题考刻条文，其中六亲考刻 154 条、定分 392 条；
- 966 条命书条文，其中命局 378 条、运限 588 条；
- 33 组枚举互斥约束；手足照料、经济供养与代亲监护拆为三项可并存的二元维度；
- 17 组全域条件规则连接家庭、关系、事业、财务、身心、迁移与转折事件，规则只采用定义与时间范围上的严格蕴含；
- 120 份回答前生成、签名唯一、可逐字节重放的候选 Profile；
- 选条使用期望信息增益，并同时控制年龄、人物存在、关系接触、前置事实、领域覆盖和停止置信门槛；
- “未明”保留记录但证据权重为零；内部不适用条文不展示、不计轮次、不更新后验；
- 命书限制同义冲突、单领域密度、重大事件密度和不合理年龄窗口；
- 卷三使用 56 组人工审校的事件判词，按年龄、锁定 Profile 与前尘领域编排，结尾明确列出寿限；
- 所有现代创作条文都标记来源策略，不冒称古籍原文。

单一真源码本位于 `src/lib/tieban-v4-codebook.ts`，与 `scripts/v4/codebook-core-v4.mjs` 及参考码本保持逐字段一致。

## 封存模拟

权威实验位于 `experiments/sealed-tieban-v4/`，正式执行 50,000 次确定性程序会话，并生成 1,500 个可复用 Persona。30/30 个预设门槛与 8/8 个隔离、复现测试通过。

主要结果：默认模型分钟命中 99.975%；带噪分钟命中 91.34%；模型外独立人生的画像 Precision / Recall 为 83.68% / 83.61%；相同输入完整重放 100%；BirthSeed 反事实命书差异 100%；问句与命书完整句直接复用率为 0。

这些数据证明工程码本在声明的合成回答模型下具备识别、纠错、隔离和重放能力，不证明真实出生分钟与人生经历存在科学因果关系，也不是真人效度结论。本轮按约定不包含真人测试。

V4.1 另有 10,000 个固定种子条件样本，覆盖无手足、共同成长、半血缘分居、代亲监护、早逝、失联疏远、三项责任并存和单次含噪回答；用于验证条件跳题、结构推断与重放。详见 `evaluation/conditional-applicability-v1.md`。该结果是工程测试，不冒充真人理解率；原文与“今解”另经模拟真人 Agent 审核。

V4.2 再以 20,000 个固定种子全域样本执行 2,320,000 次条件事实检查，并审核 27,196 个候选命籍核心事实。矛盾事件仍可用、上游未知误跳过、候选核心事实矛盾与规则写入缺失均为 0；详见 `evaluation/global-event-graph-v1.md`。未建立严格蕴含的相似事件不会被强行排除。
