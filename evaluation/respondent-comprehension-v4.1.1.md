# V4.1.1 模拟真人理解审核

## 审核方法

- 审核者是独立子 Agent，只读取人物经历、古式条文与对应“今解”，不读取模拟器真值标签。
- 以 29 个边界人物逐轴作答，覆盖独生、半血缘、继亲/寄养共同成长、双胞胎、共同生活后早逝、长期失联、父母缺位、照料与供养并存、代亲监护等情形。
- 严格标准：古式原文和“今解”必须导向同一个合理答案；存在两个合理答案或两层文本范围不一致即判失败。
- 本报告是 Agent 模拟理解审核，不是真人效度结论。

## 迭代结果

| 版本 | 严格一致 | 主要问题 |
|---|---:|---|
| 初版条件模型 | 86 / 108，79.6% | 六选一责任重叠；往来状态随时间变化而重叠；原文与今解范围不同 |
| 三维责任与往来优先级 | 148 / 158，93.7% | 三处原文额外增加前提；完全失联不足两年存在空档 |
| V4.1.1 最终复核 | 164 / 164，100% | 本组边界人物未发现双重合理答案 |

## 最终分轴

| 轴 | 严格一致 |
|---|---:|
| 实际手足数量 | 29 / 29 |
| 手足排行 | 27 / 27 |
| 往来状态 | 27 / 27 |
| 持续生活照料 | 27 / 27 |
| 持续经济供养 | 27 / 27 |
| 代亲监护 | 27 / 27 |
| **合计** | **164 / 164，100%** |

两名无实际手足者只进入数量轴，其余排行、往来和责任轴由系统内部判为不适用，不向用户展示。

## 通过的关键边界

- 血缘手足与共同成长的非血缘家人合并去重；同父异母、同母异父均计入。
- 排行使用“同枝列序”，不会把非血缘共同成长者排除；双胞胎先后不明时保留“未明”。
- 往来状态按“曾共同生活满五年”优先；否则以二十四岁时是否仍可联系、以及此前两年累计二十四次联系为界。
- 完全失联一年半不再落入空档，唯一归入“全部早逝或完全失联”。
- 生活照料、经济供养、代亲监护是三个独立维度，可以同时为“应”。
- “独生排行”是派生事实，不会重复成为考刻问题。

## 结论边界

164 / 164 说明当前 29 个预设边界人物对这六个轴可以唯一作答。它不能证明所有真实用户都能理解，也不能替代上线后的匿名漏斗、未明率和人工反馈监测。
