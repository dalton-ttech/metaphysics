## v2.3 密封合成实验

- 共 53,410 个策略臂会话、1,602,300 次问题响应；
- 规则默认与压力场景各使用 2,000 个校准样本、1,200 个独立验证样本、200 个复测样本；
- Agent persona 使用 500 个校准样本、300 个独立验证样本、30 个复测样本；
- 推荐 K=8，即总题数 32；98.1% 的定向题在选择时位于 0.25—0.88 后验区间；
- 默认规则场景：高置信 P/R 95.1% / 10.3%，候选 P/R/F1 54.8% / 84.1% / 66.3%，最低事件 Recall 25.9%，Brier 0.0976，复测候选 Jaccard 93.1%；
- 压力规则场景：候选 P/R/F1 54.1% / 81.3% / 65.0%，复测候选 Jaccard 86.2%；
- Agent persona：候选 P/R/F1 58.5% / 71.8% / 64.5%，复测候选 Jaccard 87.6%；
- K=10/12 虽提高总体 F1，但默认场景最低逐事件 Recall 降至 1.4% / 4.5%，因此拒绝；
- 核心结果 SHA-256：`eccfb30b3d7088dbe4371a869e1bfb60eb790afa490fd8bafd317926562b1ee6`。

Agent persona 是回答中的认知、记忆、敏感披露与误解模拟器，不是真人或查看真值的评分裁判。上述结果只对声明的合成分布和噪声模型成立，不外推为真人准确率。

## 产品证据约束

- 第 1—24 问负责固定覆盖和交叉复核；
- 第 25—32 问按后验信息增益选择单一候选事件，并由用户明确回答；
- “是”进入已确认画像，“否”进入排除边界，“暂难判断”保持未决；
- 命书只引用明确确认的事件 ID；某章节没有直接旧事证据时，明确显示“本轮无直接旧事证据”，不反推过去。

## 下一阶段边界
