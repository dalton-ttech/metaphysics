# 密封合成人生实验 v2.3

v2.3 不改写 v2.2，而是把其固定24题完整保留为共同基线，再比较增加 `K=0/2/4/6/8` 道单事件定向验真后的独立验证表现。如果 K=8 相比K=6仍有预注册的增益，实验自动追加K=10与K=12。

## 定向选择

每答完一题重新计算后验。候选首先限制在0.25—0.88之间，再综合：

- 单事件测试的期望信息增益；
- 事件显著性；
- 是否落在优先后验区间。

同一轮扩展不会重复事件。某事件已经获得至少两次非“不确定”且方向一致的单项证据时，会被排除，避免重复问已有充分证据的事件。没有区间内候选时才允许从区间外回退，并在结果中统计回退率。

## 样本与隔离

第一阶段采用足量规则模拟：2000个校准样本、1200个独立验证样本、200对复测；同一真值和同一问题响应跨K复用，形成配对比较。另运行一组回忆、敏感披露和复测漂移更差的压力噪声场景。

若规则组的K间候选F1/Brier差异或默认—压力差异超过预注册阈值，自动追加500个校准、300个独立验证、30对复测的Agent persona会话。

题数推荐不能只看平均F1。候选K还必须满足：校准组能找到95%高置信Precision阈值、独立验证高置信Precision不低于90%、候选Recall不低于70%、最低逐事件Recall相对K=0跨场景基线下降不超过5个百分点、候选层复测Jaccard不低于85%。5个百分点的非劣界与最低基率事件在1200人验证组中的样本分辨率相称；更窄的点估计门槛会被一两个样本左右。

`sealed-arena.mjs` 将真值逐人加密后放入私有闭包；策略只能读取公开事件目录、匿名会话描述以及当前题的“是/否/不确定”。阈值只由校准组选取，最终表格只读独立验证组。

## 运行

```powershell
cd experiments/sealed-synthetic-v2.3
npm test
npm run run
```

结果写入：

- `reports/canonical-result.json`
- `reports/experiment-summary.md`

所有发生率、潜变量和回答噪声仍是工程假设。该实验只能比较合成环境下的问答策略，不能替代真人理解率、真实披露行为或真人准确率证据。
