# V6.2 白话文审校记录

## 审校范围

- 固定界面文案：卷首、起例、考刻、刻成、待复、命书。
- 540 条“司刻释义”。
- 命书白话层：命印判断、事件影响、事件之间的关联、后程征兆、后程判断与结果。
- 古籍条文、命诀、卷名等仪式性文本不按现代白话改写，但不得承担解释功能。

## 审校标准

每句白话文都应满足：

1. 脱离前后文仍能知道所指的人、事和结果。
2. 不用“前一处、这一处、尺度、课题、主线、路径、结构”等抽象词代替具体内容。
3. 不把数据库标签或内部建模术语直接展示给用户。
4. 数量、年龄、关系与事件之间的搭配符合中文习惯。
5. 解释句使用陈述句；不将条文改写成诱导性问句。

## 代表性改写

| 原文 | 问题 | 改写 |
| --- | --- | --- |
| 前一处留下的尺度，后来在这一处变成了真实选择。 | 指代不明；“尺度”“真实选择”没有具体所指。 | “早担家责”发生后，你开始更在意家里的责任由谁承担、是否公平。后来经历“事业转折”时，你也会先考虑这件事会不会增加家里的负担。 |
| 本人四十岁前跨职业主线转轨一次。 | “职业主线转轨”是内部分类词。 | 你四十岁前有过一次明显转行。 |
| 本人四十岁前进入一次正式或事实婚姻。 | “进入一次婚姻”搭配生硬，“事实婚姻”不适合直接解释。 | 你四十岁前结过一次婚，或有过一次长期以夫妻身份共同生活的关系。 |
| 本人四十岁前发生一次非自愿职业中断。 | “非自愿职业中断”是研究术语。 | 你四十岁前有过一次因裁员、辞退、单位停业或其他外部原因失去工作。 |
| 过去积累的经验会换成更大的职责或更稳定的岗位。 | “经验换成职责”搭配不当。 | 过去积累的经验会让你承担更大的职责，或获得更稳定的岗位。 |

## 自动审核

- `npm run copy:audit`：扫描全部 540 条司刻释义，拒绝抽象指代、内部术语和已知病句句型。
- `tests/tieban-v4-book.test.ts`：审核命书白话层，并要求每条事件关联同时点明前后两个事件。
- `tests/tieban-v5-consumer-copy.test.ts`：审核消费者界面、释义句式与字体约束。
