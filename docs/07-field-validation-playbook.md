# 真人现场验证手册

> 历史 / 下一阶段文件：本轮 V3 Goal 明确不做真人测试。本文仍按旧 v2.3 的 32 问工具记录保留，不属于 V3 当前流程或发布验收；未来恢复真人研究时应先按单命题 12—26 轮流程重写。

本手册把当前版本交给线下研究团队即可执行。目标不是收集“觉得准”的评价，而是在答案不泄露给引擎的前提下，测量前半生事件画像的真实精确率、召回率、理解率和复测一致性。

## 一、冻结受评版本

1. 在 `20260720` 目录运行 `npm run release`；
2. 归档 `release-manifest.json`，记录 `modelVersion` 与 `sourceTreeSha256`；
3. 校准和独立验证期间不得修改 `src/`、题库、阈值或依赖；
4. 任何受评文件发生变化，都必须提升模型版本并重新采样。

## 二、样本分期

| 阶段 | 建议人数 | `/lab` 样本组 | 用途 |
|---|---:|---|---|
| 认知访谈 | 30—50 | `cognitive` | 判断题意、事件边界和“任中一项答是”是否被正确理解 |
| 参数校准 | 200—500 | `calibration` | 选择概率阈值，调整先验和噪声参数 |
| 独立验证 | 至少 300 | `validation` | 唯一可用于正式准确率闸门的样本 |
| 隔周复测 | 至少 30 对 | `retest` | 测量 7—14 天后的核心画像一致性 |

四组不得相互替代。独立验证样本不能回流调参；参与校准的人不能再次作为独立验证样本。

## 三、单名受试者操作

1. 研究员创建不含姓名、手机号等直接身份信息的编号，例如 `P-0128`；
2. 在受试者看到问题前，由研究员依据结构化访谈一次性标完整履历；
3. 选择正确样本组，点击“锁定履历，开始盲测”；
4. 把设备交给受试者，研究员不得解释题目所映射的事件；
5. 受试者只使用“是 / 否 / 暂不判断”；
6. 完成后点击“导出独立记录”，立即核对文件能够打开；
7. 将文件放入受控的 `evaluation/records/` 汇总目录。

履历标签必须基于明确事件事实，不得因模型输出而回改。对日期记忆不确定不影响事件是否发生的标签；对事件本身不确定时应在履历访谈阶段解决，而不是让研究员猜测。

## 四、认知访谈专用步骤

认知组每答完一题，系统会进入研究员标注页。先让受试者用自己的话复述判断规则，再标记：

- `完整理解`：知道两象任中一项即答“是”，并正确理解事件含义；
- `部分理解`：需要重读白话规则，或对一个词、时间范围、事件边界有轻微偏差；
- `理解错误`：误以为两项必须同时发生，或对关键事件含义作出错误解释。

非“完整理解”必须选择一个主要问题：措辞、事件重叠、时间边界、回忆困难、敏感回避或其他。备注只记录受试者原话与卡点，不得写姓名和联系方式。

满足下列任一条件的问题必须进入修订清单：

- 至少 5 次观察后，加权理解率低于 0.80；
- 理解错误率超过 0.05；
- 同一措辞问题被至少 3 人独立指出；
- P90 作答时间显著高于同题型中位水平。

修订后视为新模型版本，原有独立验证成绩失效。

## 五、复测规则

1. 间隔 7—14 天；
2. 继续使用第一次的受试者编号；
3. 样本组选择 `retest`；
4. 不向受试者展示第一次答案和画像；
5. 复测履历真值沿用第一次锁定版本，若确有录入错误，应记录更正原因并排除该对数据后重新纳入。

## 六、每天收尾检查

```powershell
npm run validation:merge
npm run validation:evaluate
```

合并器会拒绝：重复的“编号 + 样本组”、混合模型版本、不完整概率向量、回答与耗时数量不一致、认知组缺少逐题标注、无效题内事件数。

每日检查：

- 样本组数量是否符合现场登记表；
- 每人是否有完整的 32 条回答与对应耗时；
- 认知组是否每题都有理解标注；
- 跳过率和作答时间是否出现设备或操作异常；
- `modelVersion` 是否唯一；
- 当日文件是否完成加密备份。

## 七、最终放行标准

自动报告中的 `productGates.allPassed` 只有在以下条件全部满足时才会为 `true`：

- 认知访谈至少 30 人，完整理解率不低于 0.85，理解错误率不高于 0.05；
- 独立验证至少 300 人；
- 高置信 Precision 不低于 0.90；
- 重大事件 Recall 不低于 0.70；
- 高置信误报率不高于 0.05；
- 至少 30 对复测，Jaccard 不低于 0.85。

任何闸门未通过，都应回到问题、先验或算法层修改并建立新版本，不能只调整命书文案掩盖画像误差。
