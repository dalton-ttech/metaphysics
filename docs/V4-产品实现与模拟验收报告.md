# 铁板定刻 V4 产品实现与模拟验收报告

日期：2026-07-21  
范围：不含真人验证；采用结构化语料校验、确定性模拟命主与移动端浏览器验收。

## 一、本轮结论

本轮完成的不是表层换皮，而是对“考刻—定分—成书”链路的四项结构性修正：

1. 考刻条继续保持古籍断语体，司刻解统一改为陈述句；用户只判断“应 / 不应 / 未明”。
2. 事件库由 48 个事件族扩至 84 个，加入水险、火伤、交通伤、骨折、头面伤、腰脊、急诊、诈骗、坏账、长期贷款、再婚、异地关系、家产争议等市场常见主题。
3. 前尘命书不再保存、引用或显示考刻原句，而是从原子事实、人物、年龄窗与领域后效重新编纂人生节点。
4. 同一事件族在多个年龄窗同时得到支持时，只保留证据最强的一处，避免命书重复套用同一经历。

## 三、命书编纂规则

前尘节点只接受同时满足以下条件的事实：

- 后验值达到高置信阈值；
- 至少有一条“应”作为直接证据；
- 事实证据计数不为零；
- 同一语义事件族只取一个最强年龄窗。

页面只输出：年龄范围、人物主体、事件标题、重新编写的节点纪述、事件余波。考刻原句、概率、模型、归并过程与解释性提示均不进入命书页面。

- 生辰改为页面内三列年月日选择器，保持纸本线框，不使用通用弹窗卡片。

- 司刻解展开后显示“所断为：年龄窗，事实定义。”，没有问号或反问词。
