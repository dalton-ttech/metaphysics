# V3 单命题条文与命书内容层

## 结论

现有 V2 内容不能直接沿用为新版考刻内容层。它已经有 48 个可回答的人生事件，但主问题库仍以二至三个事件的 OR 群测为主；命书输出则主要依赖五个动态章节模板，缺少稳定卷号、条号、单条证据关系和足量可检索条文。

V3 因此采用全新的数据文件，不覆盖 `src/lib`：

- `data/v3/facts.json`：240 个带年龄窗口的原子事实；
- `data/v3/calibration-clauses.json`：240 条单命题考刻条；
- `data/v3/fate-clauses.json`：480 条命局、前运、后运条文；
- `data/v3/content-schema.json`：字段、枚举与三项内容不变量；
- `data/v3/manifest.json`：版本、固定生成时间和数量清单。

全部文案均标为“现代拟制·古籍断语体”。它们参考用户提供材料的短句、硬断与卷页结构，但不冒称古籍原文或失传秘本。

## 审计基线

| 现有内容 | 当前情况 | V3处理 |
|---|---|---|
| 人生事件本体 | 8领域、48事件 | 保留旧ID为 `legacyEventId`，按5个年龄窗口拆成240个原子事实 |
| 主问题库 | 多数是多事件 OR 群测 | 不迁移；V3没有 `eventIds` 字段，每条仅有一个 `primaryFactId` |
| 单象验真 | 已有48条白话问题 | 只作为定义参考，不直接作为古籍体条文 |
| 命书文案 | 5章动态模板 | 新建480条编号内容，按命局/前运/后运检索 |
| 来源信息 | 运行数据未逐条声明 | 所有事实与条文逐条写入现代拟制来源声明 |

## V3 数据语义

### 原子事实

一个原子事实由主体、一个事件谓词和一个年龄窗口构成。例如：

```json
{
  "id": "fact.v3.fam_early_burden.2",
  "subject": "本人及家门",
  "predicate": "较早承担持续的家庭责任",
  "timeWindow": { "minAge": 13, "maxAge": 18, "label": "十三至十八岁" }
}
```

人物与时间只是同一事件的限定条件，不构成附加问题。

### 考刻条

每条考刻条只能有一个 `primaryFactId`。用户回答固定为“应／不应／未明”，不能恢复多事件 OR 规则。

```json
{
  "displayNumber": "10002",
  "clauseText": "未及弱冠，家中诸务已多倚你",
  "primaryFactId": "fact.v3.fam_early_burden.2",
  "answerMode": { "type": "ternary", "options": ["应", "不应", "未明"] }
}
```

`interpretation` 是后台的明确判定解释，前台是否展示由体验层决定；它不承担第二个命题。

### 命书条

命书条仍保持一条一个判断方向。`conditionFactIds` 表示可以触发该条的同类年龄事实，不等于向用户同时询问这些事实。后运条属于条件式推演，本项目不验证未来是否真实发生。

## 自动校验

生成：

```powershell
node scripts/v3/generate-content-v3.mjs
```

校验并重写报告：

```powershell
node scripts/v3/validate-content-v3.mjs
```

独立测试：

```powershell
node --test tests/content-v3.validation.test.mjs
```

校验器覆盖：

1. 数量门槛；
2. 必填字段与嵌套字段；
3. ID、显示编号、卷内编号唯一；
4. 考刻条唯一 `primaryFactId` 且引用存在；
5. 每个事实恰有一条主考刻条；
6. 分号、多句末和旧 OR 规则关键词的单命题启发式；
7. 全局文本精确去重；
8. 二元字组 Jaccard 0.86 阈值的高相似去重；
9. 全部内容的现代拟制来源标注。

当前机器报告见 `docs/v3-content-validation-report.md`。

## 已知限制

1. 240个事实由原有48个事件按年龄窗口工程化拆分，年龄先验不是人口统计结论。
2. 自动单命题检测只能发现表面结构问题，不能代替真实用户的语义理解测试。
3. 480条命书内容为首版可检索语料，当前使用领域级因果框架扩写；正式运营前仍应由中文编辑逐条做节奏、禁忌和地域措辞校订。
4. `legacyEventId` 只用于兼容旧引擎，不应让新版界面重新退回多事件群测。
5. 后运条是条件式叙事，不是经过时间验证的预测结论。
