# V6.3 卷三终身流年系统与模拟验收

日期：2026-07-22  
范围：卷三“后程录”的内容、算法、页面与自动模拟；不含真人验证。

## 一、重建结论

旧版卷三只有四条摘要，固定每三年一条，不能构成传统命书常见的连续运限阅读。V6.3 改为一条完整时间轴：从命主当前年龄的下一岁开始，连续写到寿限，最后一条明确写出寿限年龄与谢世时节。

页面中的每个流年节点只保留四项：

1. 年龄或年龄段；
2. 古诗、判词或章回体句式；
3. `征兆：……`；
4. 一句简明白话判断。

节点不再显示“身心调序”“家序重定”等标题，不再增加与白话重复的“后果”句，也不在消费者页面解释生成原理。

## 二、资料依据与产品取舍

调研到的公开资料并不存在一套可以验证为唯一正统的铁板神数算法，但在产品形式上有稳定共识：完成考时定刻以后，按不同岁数取条文，并将过去与未来依次排为命书。俞樾《春在堂随笔》相关引文有“自少而长，或逐年，或逐月，历历如绘”的描述；流传案例中也可见逐岁命谱、分段运限与最终寿元。

本版本据此采用“连续年龄命书”的形式，不声称复原失传秘法。1—3 年的密度是现代产品规则：近事需要具体，远事避免把几十年切成过多同质条目。

## 三、寿限与年龄网格

寿限是确定性的产品参数，不是医学寿命模型。算法以 80 岁为基线，加入性别、出生年代、出生地散列与锁定 Profile 的小幅调整，最后限制在以下区间：

- 不低于 72 岁；
- 不低于当前年龄加 8 年；
- 不高于 96 岁。

年龄网格：

- 下一岁起的 9 年：每年一条；
- 随后 15 年：每两年一条；
- 更远年份：每三年一条；
- 寿限：单独一条。

因此任意相邻条文之间没有年龄空档，任意一条最多覆盖三年。

## 四、连续性算法

每个年龄段先计算八个领域的适用分。分数由年龄、前尘领域、Profile 稳定散列、既往出现次数与最近两条主题共同决定。

硬约束：

- 同一领域不得连续三条；
- 同一本命书不重复事件键与判词；
- 事业条文在高龄阶段自动降权；
- 健康条文随年龄提高权重；
- 晚年最后三段固定完成“整理传承—亲人照应—体力渐衰”；
- 最后一段为寿限，不再接续其他事件。

这套约束解决了随机抽句常见的矛盾：已经退休后再次反复升职、高龄连续迁居、同一两年既重病又无事等。

## 五、文体库

当前库含 56 组人工编写事件判词，覆盖家门、迁学、事业、财帛、情缘、身心、人事与转折八域。每组包含年龄适用范围、判词、征兆和白话判断。

另设 8 条与领域语义相符的公共领域古诗句，例如：

- “沉舟侧畔千帆过，病树前头万木春”；
- “会当凌绝顶，一览众山小”；
- “山重水复疑无路，柳暗花明又一村”；
- “露从今夜白，月是故乡明”。

古诗原句只在具体事件语义相合时使用，并且在整卷中的占比限制在 15% 以下。模拟实测为 1.88%。其余判词避免生造典故与堆砌意象；白话禁用“路径、结构、课题、能量、沉淀、赋能、重启、开启、新局”等 AI 式词语。

## 六、页面形态

卷三改成平铺书页时间轴，而非卡片网格：

- 顶部以朱砂线标记“今岁”；
- 按十年分卷页，每个年代只出现一次侧标；
- 条文之间用细线分隔，不使用卡片套卡片；
- 判词使用汇文明朝体并保持最高视觉权重；
- 征兆用靛青小字，白话用正文灰墨；
- 寿限段使用双线与圆形朱印收束。

移动端年代标由竖排改为横排，条文仍保持单列，不横向压缩诗句。

## 七、1,000 人模拟结果

权威测试：`tests/tieban-v4-lifetime-simulation.test.ts`

| 指标 | 结果 |
|---|---:|
| 合成命书 | 1,000 份 |
| 平均卷三条数 | 21.72 |
| 不同流年序列 | 1,000 |
| 不同寿限年龄 | 16 |
| 古诗原句占比 | 1.88% |
| 最大年龄空档 | 0 年 |
| 最大单条跨度 | 3 年 |
| 最长同领域连续 | 2 条 |
| 文体库事件覆盖 | 56 / 56 |

测试同时验证：相同输入完全重放、寿限为最后一条、寿限前三段顺序固定、整卷无重复判词、所有征兆均以“征兆：”起句、禁用词与常见重复字错误为零。
