# 铁板考刻的现代反推框架

## 1. 传统形式中可确认的共同结构

现存铁板神数资料流派互异，算法与条文版本无法证明为唯一正统，但公开叙述反复出现同一体验骨架：

1. 命主先给出生年月日和约略时辰；
2. 术者起数、拨算盘或换算数码；
3. 按数码查卷、查条，先展示可核对的六亲或旧事；
4. 命主答合或不合；
5. 术者再次起数，继续换条；
6. 多条旧事相合后，把约略时辰收束到某一刻分；
7. 刻分既定，才开始抽取完整命书。

这就是本产品要复刻的“感知流程”。研究底稿见：

## 2. 不能直接继承的部分

- 现存书籍、口传技术和网络口诀缺少统一可验证谱系；
- 不同资料的取数、加则、考刻和条文编号互相矛盾；
- 无法证明人生事件与客观出生分钟存在天然因果映射；
- 不能把后见解释、选择性记忆或巴纳姆式自我套用当成数学准确率。

因此 V3 不冒称复原失传算法，也不伪造古籍出处。它以现代拟制条文和可复现工程码本实现同样的仪式结构。

## 3. 背后的现代数学

### 二十问与信息增益

120 个候选分钟需要 log2(120)≈6.91 bit 才能无噪声区分。真人回答有误解、记忆偏差、未明和误触，因此实际需要冗余，V3 设为 12—26 轮。

每轮选择能最大降低候选熵的条文，同时兼顾事实画像信息、领域覆盖、事件显著度和文案含混惩罚。

### 纠错码

每个候选分钟对应一组理想“应 / 不应”响应签名。不同候选之间保持较大汉明距离，使一两次不一致回答不会立刻把系统带到完全错误的候选。

### 贝叶斯更新

系统不把单次答案当成绝对真值，而用条文灵敏度和特异度更新候选后验。未明不更新；后续问题可以把早期错答拉回。

### 画像与刻分分离

刻分用于仪式化索引；前半生画像只依据用户明确确认的单一事实。即使工程刻分不代表客观出生分钟，前半生节点仍可逐条追溯到用户回答。

## 4. 为什么每题只问一件事

旧版多事件 OR 问题虽然单题覆盖面大，但回答“是”后无法知道究竟哪一件发生，容易造成候选画像含糊、后续补问意图明显和命书证据不干净。

V3 每条只有一个 primaryFactId：

- 能明确解释“应”到底确认了什么；
- 能用未明表达记忆不确定；
- 能把事实直接写入命书；
- 能独立估计含混度和敏感度；
- 能做错答恢复和证据审计。

## 5. 宗教式沉浸如何转译为产品

寺庙签文、经卷和仪式体验通常由三层组成：

1. 仪式物：卷、格、数、印、固定动作；
2. 原文层：与现代口语不同但可辨认的凝练语言；
3. 解读层：由一个角色把原文解释成当事人的具体处境。

V3 对应为：

- 铁算盘数序、卷号、条号和“刻成”印；
- 半文半白的单条断语；
- 可折叠的“司刻解”和命书白话解读。

消费者页面不解释算法，不展示进度条、概率、问题总数或工程术语。

## 6. 心理效应的产品边界

巴纳姆效应、确认偏误、选择性记忆和自我实现预言都可能增强用户的主观命中感。产品可以利用仪式、叙事和解读角色提升沉浸，但工程验收不能用“用户觉得像”替代结构化证据。

因此：

- 前半生节点必须有 answer=应 的题目证据；
- 含糊氛围句不能计入模拟准确率；
- 后程可以采用预言语气，但 evidenceFactIds 必须来自已确认前尘；
- 模拟准确率只在密封真值上计算。

## 7. 最终工程选择

- 约略时辰内 120 候选；
- 240 个年龄化原子事实；
- 240 条单命题考刻条；
- 480 条命书条；
- 三态回答；
- 期望信息增益自适应选条；
- 12—26 轮；
- 至少 6 个明确应验事实后才允许正常提前定刻；
- 前半生 6—10 节点；
- 后程 1—4 节点；
- Agent persona 与密封 Oracle 模拟，不做真人验证；
- 所有条文明确标记现代拟制。
