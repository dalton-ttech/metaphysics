# V6.5 判词文学化规范

## 一、改写前基线

- 命路纪源码含 218 组判词（210 组事实族文案与 8 组兜底），全部采用 `7+7`。
- 后程录含 55 组事件模板，全部采用 `7+7`。
- 当前主要问题不是七言本身，而是所有条目都使用同一副骨架；连续阅读时，判词会显得像批量生成的对偶句。
- 部分判词把“结婚、生子、诉讼、手术”等事件换成古风同义词后直接说出，仍然属于事件说明，不具备含蓄的联想空间。

原版已经冻结在 [`backups/text-library-v6.4-20260804`](../backups/text-library-v6.4-20260804/README.md)。

## 二、写作方法

### 1. 从“改写事实”改为“搭建场景”

判词采用“兴—应”关系：前半句先落下一个能被中国读者识别的生活场景，后半句让人物处境在场景中显影。事件与结果之间的逻辑不明说，也不使用“后来、从此、因此、意味着”等说明连接词。

这与传统比兴的工作方式一致：意象不是装饰，情景本身承担含义；最好的句子会跳过中间逻辑，却仍符合日常生活经验。参考：[全国哲学社会科学工作办公室《比兴：一以贯之的传统诗学》](https://www.nopss.gov.cn/n1/2022/1128/c441752-32576019.html)、[中国社会科学网《孟郊五古的比兴及其联想思路的奇变》](https://www.cssn.cn/wx/wx_zggdwx/202208/t20220802_5442898.shtml)。

### 2. 事件只在“今解”中说透

- 判词不写：结婚、离婚、生子、手术、诉讼、失业等现代事件标签。
- 判词可写：双燕归梁、旧帘雨歇、檐下燕语、白灯数夜、朱印入门、东风忽歇。
- “今解”继续明确说明具体经历，不让用户因为诗意而无法判断是否符合自己。

示例：

- 婚姻：`双燕归梁，灯花照见两家春。`
- 新成员：`檐下燕语，小窗灯火入三更。`
- 得人相助：`寒江欲暮，隔岸忽来一叶舟。`
- 职业中断：`东风忽歇，旧席无声客自归。`

### 3. 节奏不再只有整齐七言

允许并交错使用：

- `7+7`：用于庄重、完整、需要较强断语感的节点。
- `4+7`：短句如落印，长句展开余味。
- `5+7`、`6+7`：介于断语与诗句之间，适合旧事回望。
- `7+4`、`7+5`：前句铺陈，后句骤收，适合转折、离散与定局。

硬性指标：

- 命路纪与后程录的错落句长占比均不得低于 35%。
- 每层至少出现 6 种句长组合。
- 任一单一句式占比不得超过 65%。
- 在 1,000 个模拟命书中，每一本的错落句式占比不得低于 20%，总体平均不得低于 35%。
- 每则仍保持一个中文逗号和一个句号，页面继续在逗号处换行。

### 4. 含蓄不等于无意义

每则判词至少保留一个与事件域稳定关联的文化意象。不能只写“云开、花落、山高、水长”之类可套用任何人生经历的空景；判词负责让人联想，今解负责完成核对。

## 三、自动审核

运行 `npm run literary:audit`，同时检查：

- 句长结构与节奏分布；
- 旧版直述句和过度点题词；
- 两句格式、重复判词与说明性连接词。

经典原诗引用和四字命印属于刻意保留的独立层，不计入命路纪、后程录的句式配额。
