# V4.1 条件事件与证据模型

## 目标

考刻条文只有在人物存在、目标时间窗已经完成且前置关系已确认时才可展示。系统内部区分：

- `eligible`：条文可以参与信息增益排序。
- `deferred`：前置事实尚未确认，延后并优先保留上游条文。
- `not_applicable`：前置事实明确不成立，条文不展示、不计轮次、不改候选后验。
- `unclear`：条文适用，但用户无法确认；保留问答记录，证据权重为零。

## 手足事实图

```text
实际手足总数
├─ 0：手足排行、共同生活、责任、分离等下游事实全部 N/A
└─ 1 / 2 / 3+
   ├─ 手足排行
   ├─ 12—24 岁共同生活与往来
   │  ├─ 长期共同生活
   │  ├─ 分居但稳定往来
   │  ├─ 长期疏远
   │  └─ 早逝、失联或无法往来
   └─ 12—24 岁三项可并存责任
      ├─ 持续生活照料：是 / 否
      ├─ 持续经济供养：是 / 否
      └─ 代替父母监护：是 / 否
```

“实际手足”统计到本人二十四岁：全部血缘手足（同父异母、同母异父均计），加上十八岁前以兄弟姐妹身份共同生活满五年的非血缘家人，合并去重。半血缘但未共同生活者仍计入数量。排行按这些人的出生日期计算；双胞胎等无法确认先后时使用“未明”。独生排行由数量直接派生，不重复提问。

往来轴按明确优先级只落入一项：十二至二十四岁曾共同生活满五年优先；否则先看二十四岁时是否仍有至少一名手足可以联系。仍可联系者再以此前两年与任一人的累计联系是否达到二十四次，区分“保持往来”与“长期疏远”；无人可联系者归入“全部离世或完全失联”。因此，共居后早逝、先往来后失联等时间变化不会同时命中两项，也不留下“失联不足两年”的空档。

## 时间与责任口径

- 宽泛的手足责任轴仅对年满 25 岁者启用，判断已经结束的 `12—24 岁`，不推断未来是否会承担责任。
- 持续生活照料：连续三个月以上，平均每周至少三天照料日常生活或健康。
- 持续经济供养：连续六个月以上，承担至少一半必要生活、教育或医疗开支；礼物和偶尔代付不计。
- 代亲监护：连续六个月以上，代替父母主要决定未成年手足的居住、教育或医疗事项；父母离世、离家、失能或长期不能照料均可成立。
- 三项分别判断，可以同时成立；不再用“无责任、偶尔、照料、供养、代亲”六选一。
- 12—24 岁以前或期间已经发生的显著责任，可由年龄分段的高显著性事件条文记录；其正向证据不因用户年轻而降低。

## 证据权重

贝叶斯更新使用：

```text
log W(candidate) += evidenceWeight × log P(answer | candidate, clause)
```

- `未明`：`evidenceWeight = 0`。
- 明确照料、供养、代亲监护：默认 `1.0`。
- 任一责任维度的否定事实得到肯定时，按实际责任机会加权：
  - 长期共同生活：`1.00`
  - 分居但稳定往来：`0.72`
  - 长期疏远：`0.40`
  - 早逝、失联或无法往来：`0.28`
- 旧版宽泛手足事件的否定回答：`0.55`，避免低接触产生的多个否定重复放大同一信息。

## 互斥组解析

- 某一选项明确“应”：该组解析，其余选项停止展示。
- 除一个选项外均明确“不应”：剩余选项可被解析。
- 多个选项同时“应”：视为矛盾，不解析该组。
- 固定种子测试中的重复探针仅用于验证抗单次噪声能力，不代表产品会把同一句条文原样重复给用户；产品旁证必须换用不同后果事实。

## 码本与命书一致性

- 手足数量为零时，手足排行固定为独生，依赖手足存在的核心事实和命书条目不进入候选摘要。
- 重要亲密关系数为零时，不允许生成该时间窗内的分手、背叛、异地和伴侣年龄差核心事实。
- 该时间窗内没有婚姻时，不允许生成对应时间窗的离婚、再婚核心事实。
- 该时间窗内没有子女养育责任时，不允许生成对应时间窗的子女到来核心事实。
- 父亲或母亲在 30 岁前离世时，“30 岁前没有重要亲缘离世”不能同时成为候选主事实。
- 命书编译时再次执行相同的适用性检查，不直接信任候选 `coreFactIds`。

## UI 规则

- 每条考刻条文下方固定显示“今解”，不再使用折叠入口。
- 今解必须陈述唯一可判断事实，包含必要时间范围和阈值。
- “应 / 不应 / 未明”保持现有操作；内部 N/A 不作为第四个用户选项。
