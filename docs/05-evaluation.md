# V3 模拟评估与证据边界

## 1. 本轮验收范围

本轮不做真人测试。验收对象是：

- 单命题内容结构；
- 120 候选刻分的工程可分性；
- 12—26 轮自适应流程；
- 错答恢复与复测稳定性；
- Oracle 隔离；
- 前半生命书的证据约束；
- 后程节点对已确认旧事的可追溯性；
- 移动端完整交互与生产构建。

“模拟画像准确率”表示算法对合成真值的恢复，不等于真人准确率，也不等于命理结论真实。

## 2. 密封实验设计

权威目录：experiments/sealed-tieban-v3/

- 120 个候选刻分；
- 60 条单命题实验条文，每条唯一绑定一个 primaryFactId；
- AES-GCM 密封 assignment；
- 推断端只见候选、公用条文、匿名会话与逐题“应 / 不应 / 未明”；
- 推断端没有 truth、assignment、密钥、解密或 reveal 接口；
- 预设门槛在运行前固定，结果生成后没有降低门槛。

正式样本共 8,040 个会话：

| 场景 | 样本 |
|---|---:|
| 校准 | 2,400 |
| 默认独立验证 | 1,200 |
| 压力回答 | 1,200 |
| Agent persona | 600 |
| 强制一次错答 | 1,200 |
| 强制两次错答 | 1,200 |
| 复测 | 240 |

## 4. 生产路径契约验证

独立密封实验之外，tests/tieban-v3-production-simulation.test.ts 直接调用页面使用的正式引擎、240 条正式考刻条和 240 个正式事实：

- 120/120 个生产码字全部恢复；
- 每个会话在 12—26 轮内结束；
- 每份模拟命书至少有 6 个证据支持的前半生节点；
- 每份模拟命书至少有 1 个后程节点；
- 从 120 个候选中等距抽取 40 个样本并强制第 4 题错答，Top1 恢复率不低于 90%。

该测试解决了“实验目录通过、页面引擎却走另一套算法”的集成风险。

## 5. 内容与命书闸门

- 原子事实 240；
- 考刻条 240；
- 命书条 480；
- 每条考刻条仅一个 primaryFactId；
- ID、卷内编号、展示编号全局唯一；
- Jaccard ≥ 0.86 的高相似重复组为 0；
- 720 条全部明确标为现代拟制；
- 前半生只用 answer=应 且概率 ≥0.90 的事实；
- 后程 evidenceFactIds 必须属于已输出的前半生节点；
- 确切时分与刻内分钟在定刻页、命书封面保持一致。

## 6. Agent persona 的含义

Agent persona 是带有记忆、理解、稳定性和敏感披露差异的算法模拟者，不是查看人生真值后替系统打分的裁判。理解程度由模拟参数产生；最终评分由确定性程序把预测与密封真值对齐。

若未来做命书语义审核，仍采用双层隔离：

1. 解析 Agent 只看命书，把诗性文本拆成结构化断言，不看人生真值；
2. 评分程序把结构化断言与锁定真值对齐。

无法唯一映射的氛围句记为 unscorable，不能充当命中。

## 7. 必须保留的结论边界

实验候选码本经过最小汉明距离优化，是刻意拉开相邻候选的工程纠错上界。接近满分说明人工码本可被问答系统稳定区分，不等于真实的 120 个出生分钟天然具有同样可分性。

本轮可以下结论：

- 产品流程、代码、内容、隔离、命书证据链和响应式 UI 已完成；
- 在声明的合成回答模型下，候选和画像恢复稳定；
- 无需真人测试即可完成本轮工程 Goal。

本轮不能下结论：

- 真实用户理解率或披露率达到某一数值；
- 系统恢复了客观真实出生分钟；
- 命理或未来预测具有科学效度。
