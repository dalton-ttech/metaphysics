# V5 实现与模拟验收报告

日期：2026-07-22  
范围：考刻可信度、考刻交互、命书结构、生产构建与离线模拟

## 1. 本轮已实现

### 考刻可信度

- 最少锁定轮数由 12 提高到 14。
- 选题不再只挑头部候选预测为真的条文；会主动补足反向区分条文。
- 锁定要求至少 2 个“应”、2 个“不应”、10 个独立事实和 4 个领域。
- 连续同向过长、全同向、全未明、严格机械交替不能锁定。
- 只有进入“旁证”阶段且当轮回答与头部候选预测一致，才允许定刻。
- 14 轮可“正合”；证据较慢收敛时在 18—24 轮只能“已稳”或“待复”。

### 考刻界面

- 新增八个候选刻位，显示每刻起始时间。
- 候选刻位随每一答案改变明暗；最可能刻位以靛青突出。
- 阶段改为考亲、验事、辨刻、旁证，不显示题号或百分比。
- 新增“亲、事、刻、证”四枚证据印，替代问卷进度。
- 保留浅色纸本、竖排固定条文、3D“应/不应”和陈述式司刻释义。

### 命书

- 新增 2—4 字“命印”与一条主断。
- 新增“三处铁证”，只展示已确认的高显著旧事。
- 前半生由“逐条列验”改为“命路纪”，事件之间加入余波和因果桥句。
- 新增“未问而见”，优先选择未直接询问的画像事实，且不会与三处铁证重复。
- 后程每条增加应期、征兆、变化和结果，不再只给保守主题句。
- 题目条文与命书释文分层；命书不直接使用事实定义作为解释段。

### 部署产物

- Next.js 构建目录迁移到 `next-build-v5`，避免旧 V4 预览产物文件锁。
- `npm run package` 生成独立部署包：`next-build-v5/standalone`。
- 本地生产预览继续使用端口 3051。

## 3. 实机验收

生产预览已完整走通：

`卷首 → 立命籍 → 考亲 → 验事 → 辨刻 → 旁证 → 定刻 → 命印 → 三处铁证 → 命路 → 未问而见 → 后程`

实机观察：

- 八刻盘、铁算盘、条文与3D按键在同一纸本体系内，没有卡片套卡片。
- 定刻时刻仍是第一视觉高潮；四枚证据印能解释“为什么此刻可定”。
- 命印建立可记忆的身份对象。
- 三处铁证使用和提问不同的解释层；“未问而见”与铁证不重复。
- 后程的征兆和后果已具备可观察性。

## 4. 结果边界

本轮 100% 是**内部合成码本的可恢复性**，证明选题、更新、旁证和锁定逻辑没有互相打架。它不证明现实用户会以同样稳定的方式记忆或理解人生经历，也不证明传统铁板神数的超自然真实性。

尚未完成的市场验证包括：

- 真人对条文含义的理解一致率；
- 真人记忆偏差、反悔和时间模糊；
- “三处铁证”的主观震撼度；
- 命印是否愿意分享；
- 付费转化、复访和传播系数。

这些应进入下一阶段的小规模盲测，而不应由更多合成样本代替。

## 5. 下一阶段优先级

1. 对 20—30 位真人做只读盲测，不解释算法，只记录条文理解、命中、犹豫和复述。
2. 建立命书文本相似度与个体间重复度的自动审核。
3. 为命印制作默认不含隐私事件的分享版式。
4. 增加“与某人合刻”的关系入口，形成自然邀请机制。
5. 在取得真实会话数据后重新标定事实基础率、题目歧义度和锁定阈值。
