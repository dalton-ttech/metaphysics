# V5 产品重构任务规划

版本目标：把 V4 从“中式自适应问卷 + 长报告”改造成“可感知地以旧事定刻、再由刻分开命书”的完整产品。

## 一、产品边界

### 核心产品

- 移动端优先的一次完整考刻体验。
- 通过固定条文和多轮“应 / 不应 / 未明”收敛候选刻位。
- 输出具有具体旧事、生命主线、身份命印和明确后程的命书。
- 计算与证据可重放；语言可以神秘，但不能靠临时编造事实维持命中。

### 本轮不做

- 真人用户测试。
- 真人命理师咨询市场。
- 支付、账户、社区和推送系统。
- 宣称复原某一失传的正统铁板算法。
- 把医疗、法律或财务行动交给命书决策。

## 二、V5 核心流程

### 1. 立命籍

输入姓名、生辰日期、出生地、性别与大概时辰。提交后不是直接进入问题，而是生成命籍封签、起数编号和八个候选刻位。

### 2. 起八刻

界面展示八个候选刻位。铁算盘第一次起数后，其中若干刻位亮起。此时不显示“第几题 / 总进度”。

### 3. 考亲

优先使用父母、手足、婚姻、子女等固定条文。每一答案令候选刻位改变明暗；命中一组独立证据时落一枚“亲”印。

### 4. 验事

覆盖迁移/学业、事业/财务、关系、身体/危险、重大转折。不能连续堆叠同一种灾祸，也不能只问宽泛性格。

### 5. 辨刻

当候选剩下相邻两到三个时，使用对这些候选信息增益最高、且互相排斥的条文。界面让用户看到珠位在相邻刻间移动。

### 6. 旁证

使用一条从未参与拟合的保留条文。它不是“再问八题”，而是定刻前的一次独立验算。命中才可标“正合”；否则只做“初定”或继续复算。

### 7. 定刻

显示时刻、刻位、命籍编号、证据印和锁定级别。数字出现应是全流程第一高潮。

### 8. 开命书

命书按五层展开：

1. **命印**：2—4 字身份母题 + 一句主断。
2. **三处铁证**：三个高置信旧事锚点，但用新的命书语言表达。
3. **命路**：5—7 个节点，以因果线连接，不做十条平铺。
4. **未问而见**：至少一项未直接询问、由画像关系推得的判断。
5. **后程四门**：每条包含应期、征兆、变化和结果。

## 三、内容架构

### 事实本体新增字段

- `rarity`：稀有度。
- `memorySalience`：回忆显著性。
- `answerability`：是否适合“应/不应”。
- `sensitivity`：内容强度。
- `causalTags`：可与哪些事实形成因果边。
- `identityEffects`：可能留下的处世模式。
- `counterFactIds`：互斥或反向事实。
- `holdoutEligible`：能否作为旁证。

### 领域配额

每次完整考刻至少包含：

- 六亲 2—4 条；
- 迁移/教育/事业 2—4 条；
- 关系 1—3 条；
- 身体、手术、伤痕、落水、火灾或其他危险经历 1—2 条；
- 财务、诉讼、犯罪、破产、怀孕、离婚等高强度事件按年龄适配和强度上限选取；
- 1 条不参与拟合的旁证。

### 文案三层

- `条文`：固定、简短、古白相间，可明确判定。
- `司刻解`：现代白话陈述句，只解释条文所指，不提出新问题。
- `命书`：以新的词汇、结构和视角连接事实，不复用条文句式。

## 四、数学与工程框架

### 选择模型

继续使用候选画像 + 贝叶斯更新 / 信息增益选题，但增加四个约束：

1. **证据独立性**：同一事实或同一语义家族只能贡献一次主要证据。
2. **响应模式惩罚**：连续同向或固定交替降低锁定置信，而非改变用户答案。
3. **反向区分**：正合必须包含候选预测为真和预测为假的独立证据。
4. **保留集验证**：至少一条旁证不进入后验更新，只用于锁定审核。

### 故事图

命书编译器输入不是题目文本，而是：

`事实节点 + 时间范围 + 置信度 + 因果标签 + 身份影响 + 未问推断`

编译顺序：

1. 去除互相冲突和语义重复的事实；
2. 选 3 个高显著锚点；
3. 建立至少 3 条因果或余波边；
4. 生成命印与主线；
5. 从未直接询问的节点中选一项“未问而见”；
6. 用独立模板或受约束模型生成命书；
7. 做事实一致性和文本复用检查。

## 五、UI 任务

### 保留

- 浅色纸本底色。
- 朱砂、墨、靛青和少量铜绿。
- 自定义纸本下拉列表。
- 3D “应 / 不应”按键。
- 竖排条文、卷号、封印和固定数序。

### 重做

- 考刻页顶部由阶段文字改为八刻候选盘。
- 回答后候选刻位必须发生视觉变化。
- 每 3—4 个独立证据出现一次落印反馈，替代进度条。
- 考亲、验事、辨刻、旁证四阶段具有不同的版面节奏。
- 命书改成逐层开卷，不再是一个连续长列表。
- 命印生成可分享的单屏图，默认不含具体隐私事件。

## 六、模拟验证

### 样本

- 1,000 个密封人生画像作为快速迭代集。
- 10,000 个密封画像作为最终离线验收集。
- 每个画像模拟理想回答、10% 记忆误差、20% 模糊回答、顺从型、否认型、固定交替、快速乱点七类行为。

### 指标

| 指标 | V5 门槛 |
|---|---:|
| 精确分钟 Top-1 | ≥ 75%（理想回答） |
| 四分钟桶命中 | ≥ 90%（理想回答） |
| 10% 误差下四分钟桶命中 | ≥ 78% |
| 旁证命中率 | ≥ 80% |
| 全同向/固定交替“正合”率 | < 1% |
| 输出事实矛盾率 | < 1% |
| 题目—命书最高文本相似度 | < 0.30 |
| 前半生领域覆盖 | ≥ 5 个领域 |
| 未问题命中率 | ≥ 65% |
| 命书个体间重复度 | < 20% |

准确率门槛不是宗教真实性声明，而是对本系统内部密封画像的工程验收。

## 七、执行顺序

### P0：锁定可信度

- 增加响应模式识别、证据独立性、反向区分和旁证机制。
- 增加全应、全不应、全未明、交替回答回归测试。
- 修复“12 个应即正合”。

### P1：命书真正分析

- 扩展事实元数据和故事图。
- 新建 V5 命书编译器。
- 加入命印、三处铁证、命路、未问而见、后程四门。
- 加入文本复用检测。

### P1：考刻仪式 UI

- 新建八刻候选盘和证据印。
- 划分四阶段版式。
- 加入定刻与开卷高潮。

### P2：爆款闭环

- 生成隐私安全的命印分享图。
- 设计“与某人合刻”的关系入口。
- 设计保存命书与回访应期，但本轮只做静态入口和数据契约。

### P0：验收与交付

- 跑单元测试、类型检查、构建和 10,000 样本模拟。
- 390×844、430×932、桌面三组实机截图。
- 对照 V4 基线逐项评分。
- 输出 V5 实现报告、风险清单和部署说明。

## 八、完成定义

V5 只有同时满足以下条件才算完成：

1. 主流程可从立命籍走到命书，无断链。
2. 回答会让候选刻位可见地收敛。
3. 单一响应模式不会获得“正合”。
4. 命书不复述问题，且能说明事件之间的关系。
5. 至少出现一个用户未直接回答过的前半生判断。
6. 移动端视觉保持现代简约与新中式神秘感，无卡片套卡片。
7. 自动化测试、模拟验收和截图审核全部留档。
